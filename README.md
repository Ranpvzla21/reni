# Reto Bíblico — Verdadero o Falso

Aplicación web en español para poner a prueba conocimientos bíblicos mediante preguntas de verdadero o falso.

## Características

- Tres niveles: Fácil, Intermedio y Difícil.
- Diez preguntas aleatorias por partida.
- Respuesta inmediata con explicación y referencia bíblica.
- Puntuación en tiempo real y resumen final.
- Diseño adaptable a móviles, tabletas y escritorio.
- No necesita instalación, base de datos ni claves API.

## Cómo ejecutar

Abre `index.html` en un navegador. También puedes publicarlo directamente con **GitHub Pages** desde la configuración del repositorio.

## Archivos

- `index.html`: estructura y pantallas.
- `styles.css`: diseño visual adaptable.
- `app.js`: banco de preguntas y lógica del juego.

## Publicar con GitHub Pages

1. Entra en **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige la rama `main` y la carpeta `/ (root)`.
4. Guarda los cambios y espera a que GitHub Pages publique el sitio.

Las preguntas incluyen referencias para que cada participante pueda consultar el pasaje bíblico.

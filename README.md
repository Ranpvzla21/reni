# Millonario Bíblico

Juego web en español inspirado en los concursos de preguntas y respuestas. El participante responde 15 preguntas bíblicas de opción múltiple para alcanzar el gran premio de 1.000.000 de puntos.

## Características
- 15 preguntas con dificultad progresiva.
- Cuatro opciones por pregunta y corrección inmediata.
- Explicación y referencia bíblica después de responder.
- Escalera de puntos y niveles seguros en las preguntas 5 y 10.
- Tres comodines: 50:50, público y consejo de un amigo.
- Diseño adaptable a teléfonos, tabletas y computadoras.
- No requiere instalación, base de datos ni claves API.

## Cómo jugar
Abre `index.html` en un navegador o publica el repositorio con GitHub Pages. Pulsa **Comenzar juego**, elige una respuesta y utiliza los comodines cuando los necesites.

## Publicar con GitHub Pages
1. Abre Settings → Pages en el repositorio.
2. En Build and deployment selecciona Deploy from a branch.
3. Elige la rama `main` y la carpeta `/(root)`.
4. Guarda y espera a que GitHub publique el sitio.

Las preguntas incluyen referencias para consultar los pasajes bíblicos. El comodín del público es una simulación de juego; el consejo del amigo es una pista recreativa, no una consulta real.
